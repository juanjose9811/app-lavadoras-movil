# 📱 App Móvil - Tienda de Lavadoras

Aplicación móvil desarrollada en **Flutter** para la gestión y consulta de lavadoras desde dispositivos Android.

## 🚀 Tecnologías
- Flutter / Dart
- Material Design 3

## 🛠️ Ejecución Local
1. Tener un emulador de Android activo o un dispositivo móvil conectado.
2. Ejecutar en la terminal:
   ```bash
   flutter run
